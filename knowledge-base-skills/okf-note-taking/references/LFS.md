# Git LFS Setup for OKF Note Bundles

As bundles accumulate images, videos, PDFs, and other binary assets, the git repository can become bloated. Git LFS (Large File Storage) stores the actual binary content outside the git history and keeps only lightweight pointers in the repo.

## Why route all of `assets/`?

- Fast clones and diffs for the text parts of the bundle.
- Optional lazy fetch of large media (`git lfs fetch --include` / `--exclude`).
- A single rule set that does not need updating every time a new file type appears.

## Generated `.gitattributes`

```gitattributes
# Auto-generated by okf_notes.py
# Route large media files in assets/ through Git LFS.
assets/**/*.png filter=lfs diff=lfs merge=lfs -text
assets/**/*.jpg filter=lfs diff=lfs merge=lfs -text
assets/**/*.jpeg filter=lfs diff=lfs merge=lfs -text
assets/**/*.gif filter=lfs diff=lfs merge=lfs -text
assets/**/*.webp filter=lfs diff=lfs merge=lfs -text
assets/**/*.svg filter=lfs diff=lfs merge=lfs -text
assets/**/*.mp4 filter=lfs diff=lfs merge=lfs -text
assets/**/*.mov filter=lfs diff=lfs merge=lfs -text
assets/**/*.webm filter=lfs diff=lfs merge=lfs -text
assets/**/*.pdf filter=lfs diff=lfs merge=lfs -text
assets/**/*.zip filter=lfs diff=lfs merge=lfs -text
```

## Setup steps

1. Install Git LFS:
   ```bash
   git lfs install
   ```

2. Generate `.gitattributes`:
   ```bash
   okf-notes lfs-setup
   ```

3. Commit `.gitattributes` first:
   ```bash
   git add .gitattributes
   git commit -m "Set up Git LFS for assets"
   ```

4. Add and commit assets normally. Git LFS intercepts matching files automatically.

## Disabling LFS

When initializing a new bundle:

```bash
okf-notes init my-notes --name "My Notes" --no-lfs
```
